Agent Run Receipts

What evidence accompanied this change, and has that record been altered? Not a scanner. Not proof the agent was fully constrained.

Coding agents now open real pull requests. Teams merge on a chat summary or a vendor log. Those are not a portable object.

A receipt hashes the supplied diff and (optional) transcript, records factual checks, and fingerprints itself. It cannot prove the transcript is complete or that the agent did nothing unrecorded.

You never decide when to run it.

Add one GitHub Action to a repo. Every pull request gets a receipt, posted on the PR. Install once.

uses: 5ninefish/agent-run-receipts@main
# or copy examples/install-on-your-repo.yml
